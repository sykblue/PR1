분석 화면의 저장 후 자동 학습 선택을 해제하고 사진을 모아 저장한 뒤, 로컬 학습 페이지에서 한 번 학습하면 돼요. 새 데이터가 추가되면 이전 모델은 재학습 전까지 사용하지 않아요.

03 / START HERE

촬영에서 분류까지, 네 단계

  1. 1

    사진을 촬영하거나 선택해요

    로그인 후 ‘내 헤어라인 살펴보기’에서 시작해요. 한 데이터 모음에서는 정면·정수리 등 촬영 부위와 조명·거리·크기를 되도록 일정하게 맞춰 주세요.

  2. 2

    라벨과 사람 그룹을 지정해요

    ‘이 사진으로 로컬 학습하기’에서 라벨을 직접 선택하고 익명 그룹을 입력해요. 같은 사람을 다른 코드로 나누지 마세요. 라벨을 고치려면 해당 사진을 삭제한 뒤 올바른 라벨로 다시 등록해요.

  3. 3

    저장하고 조건이 모이면 한 번 학습해요

    ‘이 사진을 학습용으로 저장’ 또는 분석 후 저장을 선택해요. 충분한 데이터가 모이면 자동 학습을 사용하거나 로컬 학습 페이지에서 실행해요. 저장과 모델 학습은 각각의 상태로 안내돼요.

  4. 4

    학습 완료 후 새 사진으로 확인해요

    분석 화면의 ‘로컬 모델로 분류’를 사용해요. ‘학습된 로컬 분류 결과를 Gemini에 함께 전송’을 선택하면 AI 관찰의 참고 자료로 보낼 수 있어요. 학습용 사진 자체를 평가용 새 사진으로 간주하지 마세요.

내 사진은 어디에 저장되나요?

분석 화면에서 저장한 사진은 data/training/users/<계정 ID>/학습/에, 학습 페이지에서 직접 등록한 사진은 같은 계정의 photos/에 보관돼요. 로컬 학습의 ‘등록한 사진 목록’에서 삭제할 수 있어요.

04 / FAQ

학습 전에 자주 궁금한 것들

학습 버튼을 10번, 100번 누르면 더 좋아지나요?

현재 앱은 누를 때마다 등록된 데이터로 새 SVM 모델을 만들어요. 이전 모델에 학습 횟수가 누적되는 방식이 아니어서 같은 데이터로 반복 실행할 필요가 없어요. 데이터의 구분과 촬영 조건, 라벨 검토가 먼저예요.

제 사진만 많이 찍었는데 왜 학습이 안 되나요?

현재 모델은 각 라벨 {{ minimum_per_label }}장 이상·사람 그룹 {{ minimum_groups_per_label }}개 이상, 전체 {{ minimum_groups_total }}개 사람 그룹을 요구해요. 같은 사람이 학습·검증 양쪽에 들어가지 않도록 나누기 위해서예요. 한 사람의 사진을 여러 코드로 나누어 조건을 맞추면 검증이 왜곡돼요. 사진 저장은 가능하지만 조건이 부족하면 학습은 대기해요.

최소 사진 수를 채우면 정확한 탈모 판별이 되나요?

이 수치는 학습 실행을 위한 최소 조건이에요. 표시되는 수치는 사람 그룹을 분리한 보류 사진에서 사용자 라벨과 일치한 비율이며 의료적 정확도가 아니에요. 결과는 조명·배경·촬영 구도의 영향을 받을 수 있어요.

사진이 충분한데도 학습이 실패하면 어떻게 하나요?

두 라벨이 학습용·검증용에 모두 포함될 수 있는지 사람 그룹과 라벨 구성을 확인해 주세요. 오류 안내를 확인한 뒤 다시 시도할 수 있어요. ‘사진은 저장했지만 학습 실패’ 안내가 나온 경우 이미 등록한 사진은 다시 저장하지 않아도 돼요.

Gemini도 같이 재학습되나요?

여기서 학습하는 것은 내 컴퓨터의 HOG·선형 SVM 사진 분류기예요. Gemini 모델은 이 기능으로 재학습되지 않아요. Gemini 호출 오류가 나도 로컬 학습을 다시 할 필요는 없으며, 학습된 로컬 분류기는 별도로 사용할 수 있어요.

준비됐으면, 한 번 시작해 볼까요?

사진을 모으고 라벨·그룹을 확인한 뒤 학습해요.
