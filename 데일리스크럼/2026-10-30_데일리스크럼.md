### 🚧 이슈와 해결
- "AI 서비스가 요청을 완료하지 못했어요"가 여러 오류를 한 문구로 묶고 있었음 → 원인별로 나누고 일시 오류만 재시도
- 공개 실시간 장소 서버가 불안정 → 실행 중 외부 조회 대신 공식 공개 자료를 내려받아 사용
- 설치된 Ollama 모델이 텍스트 전용 → 사진 분석 전에 거부하고 설치 명령을 안내 (503)
- 비전 모델 미설치로 로컬 전환 추론을 못 하던 문제 → 오후에 `qwen2.5vl:3b` 설치로 해결
- Windows 애플리케이션 제어가 torchvision 로드를 차단(WinError 4551) → 보안 설정은 그대로 두고 torchvision 없이 동작하는 버전 조합으로 고정
- 1스텝 학습에서 워밍업 때문에 가중치가 안 바뀜 → 20스텝 미만은 워밍업 끄고, 가중치가 실제로 바뀐 경우만 완료 처리
- **막힌 점**: Whale 연결 오류로 모달·위치 권한 창·터치 조작은 직접 확인 못 함
