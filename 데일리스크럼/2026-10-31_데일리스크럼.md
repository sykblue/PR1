# 10/31 (토) 데일리 스크럼 — Hairline Lab · 4일차

> 오늘의 목표: **메인 화면을 평가해 다듬고, 사진 인식을 고도화한다**

### ✅ 오늘 한 일
- **메인 화면 디자인 평가 후 3가지 개선**
  - 기능 카드 높이 216 → 312px, 그림 영역 34 → 38%로 확대
  - 제목 26px·설명 15px·시작 버튼 48px 높이로 가독성 개선 (520px 이하는 그림·설명 위아래 배치)
  - 점 표시를 "사진 분석·변화 미리보기·로컬 학습" 선택 버튼으로 교체
- **헤어라인 도우미 정리**
  - 상단 메뉴 옆 → 오른쪽 아래로 이동, 펼친 창 높이 720 → 560px
  - 메인 페이지 전용으로 제한 (분석·미리보기·이용 안내에서 제거)
- **페이지 군더더기 제거**
  - 이용 안내·비전 학습·로컬 학습의 상단 소개 제거 → 작업 카드부터 바로 시작 (접근성용 제목은 숨겨 유지)
  - 로컬 학습 `/training`은 사진 분류기 학습 전용으로 정리, 비전 학습은 별도 주소로 유지
- **로컬 학습에 카메라 촬영 추가**
  - 기존 공유 카메라 모듈 재사용, 촬영만으로는 등록·학습·전송하지 않음 (동의 + 등록 버튼 필요)
- **이마·헤어라인 사진 인식 개선**
  - 입력 사진 최대 2048px·JPEG 품질 95로 보존, 로컬 비전은 1280px 제한, 단색 사진은 호출 전 거절
  - 프롬프트 `hair-observation-v4-evidence`: 이마 피부와 두피를 나눠 근거를 요구, 근거가 부족하면 판단 보류
  - 이마 높이·M자 모양만으로 후퇴·탈모를 확정하지 않도록 규칙화
- **병원 찾기 모달 재디자인**
  - 시작 화면을 검색 배너 하나로 합침, 탭은 파란 글자·밑줄로 선택 표시, 최대 800px
  - 병원 목록 카드(병원명 15px·주소·거리) + 상세 내부 스크롤, 760px 이하 세로 배치
