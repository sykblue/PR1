# 11/02 (월) 데일리 스크럼 — Hairline Lab · 6일차

> 오늘의 목표: **새 탈모 데이터셋으로 공통 두피 참고 모델을 학습하고, 사진 DB 저장과 약 안내를 실제 자료로 채운다** (15:50 기준)

### ✅ 오늘 한 일
- **새 탈모 데이터셋 검토** (한국인 두피 상태 이미지, TAR 4개 · 약 4.37GB)
  - 원본은 그대로 두고 JPG 18,513장 전체의 CRC·픽셀 디코딩·SHA-256 검사 → 읽기 오류 0건, 전부 640×480 RGB
  - 등급: 양호 534 · 경증 13,346 · 중등도 3,797 · 중증 836장
  - 이름은 다르지만 내용이 같은 완전 중복 2,215쌍 발견 → 제거하면 16,298장
- **Gemini·Ollama 공통 두피 참고 모델 학습**
  - Gemini·Ollama 가중치는 그대로 두고, 로컬 MobileNetV3 Small 분류기 결과를 두 모델에 **같은 참고 자료**로 전달
  - 학습 11,047 · 검증 2,891 · 테스트 2,360장으로 분할 (같은 이미지가 세트 사이에 겹치지 않게)
  - 6회 학습 → 검증 macro-F1 기준 4회차 선택 → ONNX로 변환해 웹은 OpenCV CPU로 추론 (PyTorch 미추가)
  - 프롬프트 `hair-observation-v5-scalp-reference`: 데이터셋 라벨을 진단처럼 옮기지 않고, 불확실하면 등급 보류
  - 사진 분석 추가 옵션 "두피 확대 촬영 사진에 학습 모델을 함께 사용해요" (기본 꺼짐)
- **계정별 사진을 SQLite에 저장**
  - `photos` 테이블: 계정 ID·용도·JPEG BLOB·크기·SHA-256·라벨 저장, 파일명·EXIF/GPS는 보관 안 함
  - 분석 사진 저장은 별도 선택(기본 꺼짐), 리포트와 사진을 한 트랜잭션으로 저장, 리포트 삭제 시 사진도 삭제
  - 본인 계정만 사진 조회 가능, 로컬·비전 학습 사진도 DB와 동기화
- **약 안내를 실제 자료로 교체**
  - 식약처 의약품안전나라에서 정상 품목 20종 확인: 미녹시딜 외용 6 · 알파트라디올 1 · 피나스테리드 5 · 두타스테리드 5 · 복합 보조치료 3
  - 종류별/제조·수입사별(13곳) 묶음, 제품명·성분·제형 검색, 필터·초기화, 품목마다 공식 원문 링크
  - 제품 20개마다 실제 품목 사진 연결 (식약처 포장 사진 17 · 낱알 식별 1 · 제조사 제공 2), 출처는 `docs/의약품_제품사진.md`
  - 기존 AI 생성 약 이미지와 성분 소개 블록 제거
- **8000번 서버 재시작** → 로그인·회원가입이 공통 헤더로 정상 표시

### 🎯 두피 분류기 정확도 보고
- 모델: MobileNetV3 Small (ImageNet 사전학습) · 6회 학습 중 검증 macro-F1 기준 4회차 선택
- 데이터: AI Hub "한국인 두피 상태 이미지" 탈모 부분 18,513장 → 중복 제거 16,298장 → 학습 11,047 · 검증 2,891 · 테스트 2,360장

| 지표 | 검증 (2,891장) | 테스트 (2,360장) |
| --- | --- | --- |
| 정확도 | 66.7% | **65.8%** |
| 균형 정확도 | 61.9% | **61.2%** |
| macro-F1 | 0.556 | **0.520** |
| 기준선: 모두 "경증"으로 답할 때 | 71.1% | **74.1%** |

| 등급 (테스트) | 장수 | 정밀도 | 재현율 | F1 |
| --- | --- | --- | --- | --- |
| 양호 | 61 | 38.7% | 75.4% | 0.51 |
| 경증 | 1,749 | 88.5% | 68.8% | 0.77 |
| 중등도 | 460 | 35.0% | 57.4% | 0.43 |
| 중증 | 90 | 30.7% | 43.3% | 0.36 |

- 가장 많이 틀린 경우: 경증 → 중등도 457장, 중등도 → 경증 125장, 경증 → 양호 63장, 중등도 → 중증 63장
- 해석: 정확도가 기준선(74.1%)보다 낮음. 클래스 가중치 때문에 적은 등급(양호·중증)을 더 자주 고르는 대신 경증을 놓침 → 균형 정확도·macro-F1로 보고
- 참고 비교: Kaggle "두피 이미지를 통한 두피 질환 및 탈모 진단 예측"(2022 텀프로젝트, 12,730파일·3.1GB) 최고 정확도 60.8%. 두피 **종류** 4분류(정상·비듬·염증·탈모)라 우리 **탈모 정도** 4분류와 직접 비교 불가. 공통으로 두피 확대 4분류는 간단한 모델에서 60%대
- 한계: 같은 수령본 안의 내부 평가이며 외부 검증·임상 성능이 아님. 일반 헤어라인 사진에는 적용 근거 없음

### 🚧 이슈와 해결
- 완전 중복이 ID가 다른 사진 사이에도 있음 → 중복을 먼저 제거한 뒤 대표 ID로 분할
- 경증이 72%로 쏠림 → 클래스 가중 손실 사용, 검증 macro-F1로 최종 회차 선택
- 사진 저장 중 실패하면 파일과 목록이 어긋날 수 있음 → SQL·목록 저장 실패 시 이전 상태로 되돌리도록 처리
- **막힌 점**: 두피 분류기 전체 일치율(65.8%)이 "모두 경증"으로 찍는 기준선(74.1%)보다 낮음 → 정확도 향상으로 표현하지 않음
- **막힌 점**: 데이터셋은 두피 확대 사진이라 일반 이마·헤어라인 사진 분석이 좋아진다는 근거는 없음, 임상 성능도 아님
- 약 안내 모달은 분석 리포트가 있어야 열림 → 점검에서는 모달을 직접 열어 약 탭 화면을 확인
- **막힌 점**: 분석 사진이 실제로 저장된 리포트의 "내 기록 사진" 표시는 실제 분석이 필요해 아직 확인 못 함
