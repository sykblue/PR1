# 10/28 (수) 데일리 스크럼 — Hairline Lab · 1일차

> 오늘의 목표: **주제를 정하고, 기초를 잡고, 시험용 API로 구조를 세운다**

### ✅ 오늘 한 일
- **주제 정함**: 사진으로 헤어라인·두피 노출을 *관찰*하고, 가상 모발 변화를 *비교*하는 로컬 웹앱
  - 의료 진단이 아니라 관찰 도구로 범위를 정함 → 확률·중증도·진행 예측은 만들지 않음
- **기초 잡음**
  - Python 3.12 가상환경 별도 준비 (시스템 기본 3.15 대신)
  - Flask + Waitress 로컬 서버, 화면은 HTML·CSS·JS
  - API 키는 서버의 `.env`에만 둠 → 브라우저로 비밀키가 나가지 않음
  - 사진은 요청 중 메모리에서만 처리하고 EXIF 등 메타데이터 제거
- **시험용 API로 구조 잡음**
  - Gemini 2.5 Flash 관찰 리포트 연결 구조 (프롬프트 `hair-observation-v1`, 결과는 정해진 JSON 형식)
  - 실제 키 없이 **모의 응답**으로 성공·잘못된 JSON·인증 실패·할당량 초과·시간 초과 흐름을 먼저 검증
  - MediaPipe 모발 영역 표시 → OpenCV 헤어라인·정수리·밀도 가상 합성
- **구조 위에 올린 기본 기능**
  - PaddleOCR 문자 추출 → Gemini 보조 자료로 전달 (프롬프트 `v2-assisted`)
  - 로컬 사진 학습 (HOG + 선형 SVM, 같은 사람은 학습·검증에 나눠 넣지 않음)
  - 카메라 촬영, 회원가입·로그인, SQLite 기록 저장
- **발표 자료 초안** (PPT·PDF 12장)

### 📊 진행 상황

- 실제 모델로 OCR 3줄 추출 확인 (한국어·영어·숫자)

### 🚧 이슈와 해결
- MediaPipe 설치 중 OpenCV가 두 종류 설치됨 → `opencv-contrib-python` 하나로 정리, 버전 고정
- 가상 합성 때 피부색 대신 배경색을 집어 옴 → 얼굴 중앙에서 먼저 색을 고르도록 수정
- Windows에서 PaddleOCR DLL 오류 → chardet 5.2.0, pandas 2.2.3으로 버전 고정
- **막힌 점**: Gemini API 키가 없어 실제 호출·프롬프트 v1·v2 비교를 못 함 (모의 응답으로만 검증)
