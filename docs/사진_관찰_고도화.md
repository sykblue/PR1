# 이마·헤어라인 사진 관찰 고도화

사용자가 문자 OCR 대신 이마·헤어라인 사진 인식 개선을 요청한 범위다. `/api/ocr`와 문자 인식 모델은 변경하지 않았다. 프롬프트는 `hair-observation-v4-evidence`, 근거 검증은 `hair-evidence-v1`이다.

## 입력과 API 요청

- `/api/analyze`는 원본을 최대 2048px로 읽는다. 분석 사진은 JPEG 품질 95·색상 서브샘플링 0으로 인코딩하며 확대하지 않는다. Ollama와 로컬 어댑터는 같은 품질에 최대 1280px를 사용한다. 위치·EXIF는 포함하지 않는다.
- 단색 또는 형태 차이가 거의 없는 이미지는 AI 호출 전에 422로 거절한다. 64×64 표본의 채널별 표준편차 최대값 1 미만이라는 제한적인 입력 검증이며 이 값으로 사람·탈모·의학적 화질을 판정하지 않는다.
- Gemini 요청은 설명을 사진보다 먼저 전달하고 온도 .1·출력 상한 6144 토큰을 사용한다. 기존 2.5 계열은 최대 1024 thinking 토큰, 3·4 계열은 LOW thinkingLevel을 사용하고 다른 모델에 해당 옵션을 강제로 넣지 않는다. 모델·키·요금 설정은 바꾸지 않았다. 처리 시간과 토큰 사용량은 증가할 수 있다.
- 새 추가 분석 호출이나 다수결은 없다. 기존 일시 오류 재시도·429일 때만 로컬로 전환하는 정책을 유지한다.

## 관찰 근거 분리

기존 결과 항목에 다음 `visual_evidence`를 추가했다. 이마 피부는 헤어라인 바깥 영역이며 모발 영역 안에서 머리카락 사이로 보이는 두피와 구분한다.

| 필드 | 의미 |
| --- | --- |
| `image_type` | 실제 사진·일러스트·기타 |
| `target_visibility` | 선택 부위가 선명함·일부 가림·보이지 않음 |
| `forehead_skin` | 이마 피부의 노출 |
| `scalp_in_hair` | 모발 영역 안의 두피 노출 |
| `confounders` | 조명·각도·머리 모양·흐림·가림 |
| `basis` | 실제 보이는 위치와 근거 |

이마 높이·M자 외곽선·머리를 뒤로 넘긴 모양만으로 탈모·과거 대비 후퇴·선천적 원인을 확정하지 않도록 지시한다. 이마만 보인다는 근거와 `visible` 표시가 충돌하거나 선택 부위가 충분히 보이지 않으면 서버에서 `unclear`로 보류한다. 일관된 모발 사이 노출 관찰은 유지하고, 일러스트·기타 입력으로 응답하면 422를 반환한다.

Gemini·Ollama의 새 응답은 근거 필드가 필수다. 없거나 잘못된 값은 형식 오류로 처리하며 근거를 만들어 넣지 않는다. `quality_review`에 정책 버전·일관/가림/충돌/기존 근거 없음 상태를 기록한다. `cause_assessable`은 항상 false이며 정확도 점수가 아니다.

화면과 텍스트 내보내기에 ‘이마와 모발 영역 구분’을 포함한다. 새 상태 표시는 ‘모발 사이 두피 노출’로 구체화한다. 이전 저장 보고서는 재추론하거나 내용을 변경하지 않고 기존 문구로 표시한다.

## 기존 학습 자료와 호환

기존 비전 학습 정답의 6개 항목과 어댑터는 계속 읽는다. 학습 시 기본 지시는 기존 정답 형식과 맞춰 유지하고 새 사진 추론에서는 최신 지시를 사용한다. 기존 어댑터가 분리 근거를 주지 못하면 분석을 보류한다. 사용자 사진·정답·가중치를 자동 수정하거나 재학습하지 않는다.

## 검증 범위와 한계

이마만 노출된 결과·잘못된 양성 표시·실제 모발 안쪽 노출·가림·잘림·일러스트·근거 없는 기존 형식·잘못된 근거를 모의 응답으로 검증한다. 고해상도·메타데이터 제거·단색 차단·동일한 클라우드/로컬 정책·저장·내보내기도 확인한다. 이는 처리 규칙의 검증이며 실제 환자 사진의 진단 정확도를 의미하지 않는다.

합성 일러스트를 실제 로컬 `qwen2.5vl:3b`에 전달해 13.6초 뒤 `photo_not_usable` 422를 확인했다. Gemini는 제한된 실행 환경에서 연결되지 않았지만 네트워크 권한이 있는 환경의 재검증에서 새 스키마와 추론 설정을 처리하고 7.5초 뒤 같은 422를 반환했다. 두 확인 모두 사용자 사진·기록을 사용하지 않았다. 임상 정답 사진과 실제 전후 사진 집합을 사용하지 않았으므로 민감도·특이도·실제 사진 정확도 향상은 아직 측정하지 않았다.
