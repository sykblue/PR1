# 사진 분석 화면 디자인

현재 기준은 [공통 디자인](../디자인.md)과 사용자 제공 [리디 참고 문서](references/RIDI_사용자제공.md)다. 이전 분석 전용 SEED 적용은 [이력](references/analysis-design_이전기준.md)으로 보관하며 현재 규칙으로 사용하지 않는다.

## 화면 구조

- 사용자가 삭제한 PHOTO ANALYSIS 배지·소개 제목·소개 문구를 다시 넣지 않는다.
- 상단의 얇은 도구 모음에 진행 단계·연결 상태·촬영 안내를 표시한다. ‘사진 분석 공간’ 제목과 ‘사진을 선택해 시작해 주세요’ 안내 문구는 표시하지 않는다. 접근성용 페이지 제목은 화면에서 숨긴다.
- 너비 992px·높이 600px 이상에서는 사진 → 관찰 설정 → 리포트를 같은 높이의 가로 3열로 표시한다. 본문과 헤더가 화면 너비를 채우며, 공통 푸터는 숨겨 전체 페이지 스크롤 없이 작업한다.
- 분석 실행 버튼은 설정 카드 하단에, 복사·텍스트/JSON 저장은 리포트 카드 하단에 고정한다. 긴 관찰 결과·오류 안내와 펼친 추가 옵션은 카드 내부에서 스크롤한다. 사진 카드도 높이가 부족하면 내부에서 스크롤하며, 스크롤 영역은 키보드로 접근할 수 있다.
- 전송 동의와 기록 저장은 항상 기본 설정에 남긴다. 학습·로컬 분류·모발 영역 확인은 ‘추가 옵션 · 로컬 기능’에 접어 둔다. 자동 학습 설정에 오류가 있으면 접힌 항목을 열고 필수 라벨로 포커스를 옮긴다.
- 헤어라인 도우미는 메인 페이지에서만 제공한다. 분석 페이지에는 도우미 버튼·최소화 바·대화 창과 전용 JS/CSS를 포함하지 않는다.
- 작은 화면과 높이가 600px 미만인 창에서는 사진 → 설정 → 리포트 순서의 일반 스크롤 화면을 유지한다. 분석 완료 후 결과로 이동하는 동작은 이 화면에서만 수행하며 움직임 줄이기 설정을 따른다.
- 빈 리포트의 문어 일러스트와 실제 분석·저장 동작을 유지한다.
- 새 사진 관찰 리포트는 ‘이마와 모발 영역 구분’에 이마 피부·모발 사이 두피·관찰 부위의 가시성과 근거를 표시한다. 상태 표시는 ‘모발 사이 두피 노출’로 명확히 하고, 가림이나 근거 충돌은 판단을 보류한다. 이마 높이만으로 탈모나 선천적 원인을 확정하지 않는다. 기존 저장 리포트는 원래 문구를 유지한다. 입력·검증 정책은 [사진 관찰 고도화](사진_관찰_고도화.md)를 따른다.
- 완료 리포트에는 ‘병원 찾기 / 약·치료제 안내’ 버튼으로 최대 800px의 ‘진료 안내’ 모달을 연다. 사용자가 제거한 다음 행동·변화 확인·상담 준비·해당 AAD 링크와 관련 상태는 다시 넣지 않는다. 빈 열 없이 상단 두 탭과 본문으로 구성하며 선택 탭은 파란 글자·밑줄·굵기로 표시한다. 내부 스크롤·닫기·Esc·배경 클릭·포커스 복귀·탭 키보드 이동을 유지한다. 세부 동작은 [추천 로직](추천_로직.md)을 따른다.
- 병원 탭의 주소 입력과 Google 지도 연결은 제거한다. ‘내 주변 병원 보기’는 최대 980px의 두 번째 모달에서 병원 목록과 상세 정보를 좌우로 표시하며 작은 화면에서는 세로로 전환한다. 반경·위치 권한·검색 대기·실패·결과 없음 상태를 제공한다. 하단 공통 출처·기준일·현황 차이·위치 미저장 안내 블록은 제거하고 ‘안내로 돌아가기’ 버튼만 둔다. 위치는 같은 서버의 공개 자료 거리 계산에만 사용한다.
- 병원 탭은 반복 소개 없이 검색 배너부터 시작한다. 배너 안에는 위치 아이콘·제목·짧은 설명과 파란 검색 버튼을 두고, 아래에는 방문 확인 2항목과 접이식 위치 이용 안내를 배치한다. 위치 확인 시점·미저장 안내는 항상 보인다. 결과 목록은 연한 중립 배경 위의 12px 곡률 카드로 구분하며 병원명 15px·주소 12px·거리 12px을 사용한다. 선택 병원에는 파란 테두리와 ‘선택됨’ 문구를 함께 표시한다. 상세는 병원명·신고 정보·주소/전화/운영 시간 순으로 배치하고 데스크톱의 내부 스크롤과 하단 주소 복사·전화 버튼을 분리한다. 모바일은 목록 다음 상세를 표시하며 높이 600px 미만에서는 결과 모달 전체 스크롤로 전환한다.
- 약 탭의 기존 성분 소개 사진 3개·공통 사진 출처/상담 문구·AAD/NHS 링크 블록을 제거했다. 제품 20개 각각에 해당 품목의 사진을 넣으며 아보투윈은 실제 낱알 사진으로 표시한다. 사진은 카드 상단에 contain으로 전체를 보여 주고 클릭하면 크게 볼 수 있다. 각 카드의 짧은 사진 출처 링크와 제품 정보 링크를 구분한다. 첫 모달 하단은 ‘리포트로 돌아가기’ 버튼만 오른쪽에 둔다.
- 약 탭 아래에 의약품 20종 목록을 두며 종류별/제조·수입사별 보기와 검색·종류·업체 필터를 제공한다. 제품 카드는 데스크톱 2열·600px 이하 1열이며 제형·일반/전문 구분·성분·업체·위탁 제조·허가 효능 요약·식약처 원문을 표시한다. 기존 사진을 신규 제품의 개별 사진으로 재사용하지 않는다. 결과 수와 빈 결과·초기화·확인일을 표시하며 분석 상태 변경 시 필터도 초기화한다.

## 공통 디자인 적용

| 요소 | 적용 |
| --- | --- |
| 진행 단계 | 중립색 숫자·글자, 현재 단계만 파랑과 굵기로 강조 |
| 사진·설정·리포트 | 흰 면, 1px 선, 4px 모서리, 데스크톱에서 같은 높이 |
| 관찰 항목 | 기존 2×2 배치, 12px 선택 카드와 실제 라디오 선택 표시 |
| 전송·저장 | 연한 중립색 면과 얇은 선으로 구분 |
| 분석 실행 | 기존 48px 파란 버튼, 18px 모서리, 기존 글자 크기·굵기 |
| 보조 행동 | 흰색·중립색 버튼과 44px 이상 조작 영역 |
| 학습·로컬 자료 | 기본으로 접힌 native details/summary와 펼침 아이콘 |
| 결과·오류 | 실제 내용과 상태 문구, 중립색 결과 구획·기능색 안내 |

`static/analysis-theme.css`는 분석 페이지에만 적용한다. 기존 파일 안에서 데스크톱 워크스페이스의 배치·높이도 관리하며 새 전역 테마를 추가하지 않는다. 내부 `--analysis-*` 변수는 공통 색상 토큰을 가리키며 별도 브랜드 팔레트가 아니다. 본문 밖의 독립된 추천 모달은 `static/recommendations-dialog.css`에서 공통 토큰으로 관리한다.

버튼·입력·상태와 보조 창의 세부 표현은 [One UI 참고 컨트롤 기준](control-design.md)을 따른다. 사진·설정·리포트의 열 구성과 바깥 카드 모양·크기·제목·문구는 그대로 유지한다.

## 유지할 기능과 검증

카메라, 사진 점검, 관찰 부위, 선택적 로컬 학습, Google 전송 동의, 리포트 저장·복사·내보내기, 사진 이어 쓰기를 유지한다. 스타일 수정으로 동의 항목을 미리 선택하거나 분석을 자동 실행하지 않는다.

기존 분석·카메라·학습 등록·사진 전달 테스트와 실제 HTML ID·레이블·정적 자산 연결을 확인한다. 사용자 사진으로 AI를 호출하거나 새 임상 성능을 측정한 것으로 표현하지 않는다.
