- 자료: [전국 병의원 및 약국 현황](https://www.data.go.kr/data/15051059/fileData.do), [공식 메타데이터](https://www.data.go.kr/catalog/15051059/fileData.json)
- 현황 기준일: **2026-09-30**. 등록 2026-10-19, 수정 2026-10-20, 분기별 자료.
- 이용허락: **공공누리 제1유형(출처표시)**. 앱의 병원 모달과 추출 JSON에 제공기관·기준일·출처·이용허락을 표시한다.
- 다운로드한 원본 ZIP: 20,609,715바이트, SHA-256 `ceff684b8eb1dc9059b668ec56bc91d2a643997420733b2996a0bc5d8910f9c3`.

## 추출 기준

`scripts/prepare_clinics.py`는 원본의 CP949 CSV 세 개를 암호화요양기호로 결합한다.

| 원본 CSV | 사용하는 정보 |
| --- | --- |
| `1.병원정보서비스(2026.9.).csv` | 기관명·주소·전화·위도·경도 |
| `4.의료기관별상세정보서비스_02_세부정보(2026.9.).csv` | 요일별 등록 진료 시작·종료 시간 |
| `5.의료기관별상세정보서비스_03_진료과목정보(2026.9.).csv` | 피부과 신고·과목별 전문의 수 |

진료과목이 피부과이고 과목별 전문의 수가 양의 정수인 기관만 포함한다. 국내 범위의 유효한 좌표를 확인하고 원본 식별자는 SHA-256 앞 16자리로 대체한다. 빈 운영 시간·유효하지 않은 시각은 채워 넣지 않는다. 산출물은 `data/clinics-20260930.json`, **1,744개 기관 / 708,818바이트**다.

이는 현재 전문의 근무·탈모 진료 가능 여부·영업 여부를 보증하는 목록이 아니다. 신규·폐업·주소 변경·미신고 시간이 반영되지 않을 수 있다. 기준일을 화면에 표시하고 방문 전 병원에 확인하도록 안내한다. 국내 자료이므로 해외 위치에서는 결과가 없을 수 있다.

## 조회와 위치 처리

버튼을 누른 뒤 브라우저 위치를 소수 셋째 자리로 줄여 같은 서버에 POST한다. 서버는 이 JSON에서 Haversine 직선 거리를 계산하며, 반경 2/5/10km 중 가까운 최대 20곳과 전체 일치 수를 반환한다. 도보·차량 이동 거리는 아니다.

검색 중 외부 지도·병원 API·AI에 요청하지 않고 사용자 위치를 저장하지 않는다. 요청은 좌표·반경만 허용하며 CSRF·동일 출처 검사를 적용한다. 자료가 없거나 손상된 경우 임의의 기관을 만들어내지 않고 서비스 오류를 반환한다.

## 갱신

공식 페이지에서 최신 분기 ZIP을 내려받고 출처·이용허락·기준일·CSV 필드를 확인한 뒤 실행한다. 표준 라이브러리만 사용하며 API 키가 필요하지 않다.

```powershell
.\.venv\Scripts\python.exe scripts\prepare_clinics.py .cache\hira-20260930.zip
```

다음 분기는 `--as-of YYYY-MM-DD --output data/clinics-YYYYMMDD.json`으로 별도 생성한다. `services/clinics.py`의 기본 파일, HTML의 초기 기준일, 이 문서와 번들 자료 검증 테스트의 날짜·수를 함께 갱신하고 서버를 재시작한다. 자료 추출·거리 검색·CSRF 검증은 `tests/test_clinics.py`에서 확인한다.
