# 이전 사진 분석 페이지 디자인 기준

이 문서는 개편 이전의 이력이다. 현재 작업에는 [현행 디자인 기준](../../디자인.md)과 [분석 화면 기준](../analysis-design.md)을 적용한다.

적용 대상은 `/analysis`다. [사이트 공통 디자인](../디자인.md) 위에 사용자 제공 [SEED Design 문서](references/SEED-Design_사용자제공.md)의 컴포넌트 원칙을 선택적으로 적용한다. 사용자가 요청한 **기존 색상과 사이트의 통일성**이 우선이다.

## 유지하는 기준

- 브랜드 파랑 `#0066FF`, 흰 바탕, 기존 중성색·상태색과 글꼴 스택을 유지한다.
- 상단 공통 헤더·계정·챗봇과 다른 페이지의 디자인은 바꾸지 않는다.
- 삭제한 소개 배지·큰 제목·소개 문구를 다시 넣지 않는다.
- 사진 선택·관찰 리포트의 동일한 폭과 높이, 아래쪽 관찰 설정, 문어 일러스트를 유지한다.
- 실제 입력·분석·학습·저장·사진 전달 기능과 동의 조건을 유지한다.

## 첨부 문서에서 적용한 원칙

| 원칙 | 분석 화면에 적용한 방식 |
| --- | --- |
| 역할 기반 색상 | 기존 토큰을 페이지 내부의 표면·선택·액션·글자·테두리 역할에 연결 |
| 표면·테두리로 층 구분 | 흰 카드, 중성색 입력·실행 영역, 얇은 테두리로 구분하고 새 그림자·그라디언트는 추가하지 않음 |
| 브랜드 색상 절제 | 주요 분석 버튼과 현재 단계·선택·포커스에 파랑을 사용하고 보조 행동은 중립색으로 표시 |
| 둥근 액션 버튼 | 주요 버튼에 pill 형태를 적용하고 주요·보조 행동의 위계를 구분 |
| Select Box·Radio | 기본값을 유지하고 네 개 관찰 부위를 설명·선택 표시가 있는 세로 카드로 구성 |
| Accordion | 학습·로컬 보조 자료에 native details/summary를 사용하고 전체 summary에 조작 영역과 열림 표시 제공 |
| Attachment Input·Image Frame | 파일 선택, 촬영, 미리보기·변경·삭제 상태의 테두리·반경·정보 위계를 통일 |
| Field·Checkbox | 레이블·도움말·동의 항목을 구분하고 전송·저장 확인을 별도 실행 영역에 배치 |
| Result Section·Callout | 빈 리포트·분석 중·완료·오류를 구분하고 상태 의미와 복구 안내 유지 |
| 작고 기능적인 모션 | 색·테두리·펼침 아이콘에 150ms 전환을 사용하며 동작 줄이기 설정에서는 제거 |

## 공통 토큰과의 대응

`static/analysis-theme.css`에서만 아래 역할을 정의한다. 색 리터럴을 새로 만들거나 공통 팔레트를 덮어쓰지 않는다.

| 분석 역할 | 공통 토큰 |
| --- | --- |
| `--analysis-layer-default` | `--bg-surface` |
| `--analysis-layer-fill` | `--bg-subtle` |
| `--analysis-layer-selected` | `--bg-brand-faint` |
| `--analysis-action` | `--brand-primary` |
| `--analysis-text` | `--fg-default` |
| `--analysis-text-muted` | `--fg-secondary` |
| `--analysis-stroke` | `--border-card` |

텍스트는 첨부 문서의 작은 스케일(11/15, 12/16, 13/18, 14/19, 16/22, 18/24px)을 참고한다. 긴 설명은 줄 높이를 보정하고, 기존 글씨 축소 요청에 맞춰 큰 소개 타이포그래피를 추가하지 않는다.

카드는 16px, 내부 구획은 12px, 작은 필드는 8px 반경을 사용한다. 간격은 두 문서가 공유하는 4/8/12/16/20/24/32px 위주로 구성한다. 주요 실행 버튼은 48px, 작은 동작은 최소 44px 조작 영역을 확보한다.

## 적용 범위와 검증

- 전용 CSS는 `#analysis-content` 내부에 한정하고 공통 CSS 다음에 불러온다.
- 공통 반응형 구간을 유지한다. 같은 크기의 사진·리포트 카드와 설정 내부 2열은 작은 화면에서 순차 배치한다.
- 색상뿐 아니라 텍스트·라디오 선택·현재 단계·확장 상태로 의미를 전달한다. 네이티브 키보드 조작과 포커스 표시를 유지한다.
- 대비는 프로젝트의 기존 WCAG 비율 기준으로 확인한다. 첨부 문서의 모든 토큰·패키지·테마·APCA 목표를 그대로 구현한 것으로 표현하지 않는다.
- 외부 패키지·당근의 브랜드 자산·로고·서비스 개념을 도입하지 않고 제품 화면에 디자인 시스템 이름을 표시하지 않는다.
