미녹시딜 사진은 외용 로게인 제품이며 파일 설명의 촬영 시점은 1996년 이전이다. 현재 국내 포장이나 특정 제품의 판매 상태를 보여 주는 사진으로 표현하지 않는다. 피나스테리드는 출처가 해당 성분으로 명시한 정제 사진, 영양제는 비타민 B 제품 사진이다. 외형만으로 성분을 새로 추정하지 않았다.

화면에는 **실제 제품 예시 / 실제 정제 예시 / 실제 영양제 예시**로 표시한다. 국가·제조사·촬영 시점에 따라 포장이 다를 수 있다는 설명과 특정 제품·개인별 복용을 추천하지 않는다는 안내를 함께 둔다. 미녹시딜 용기 사진은 CSS `object-fit: contain`으로 전체를 보이며 다른 사진은 기존 카드 프레임에 표시한다.

각 사진의 출처 링크·저자·라이선스 링크와 내용 무편집 표시는 약 탭의 **사진 출처·이용 조건** 펼침 영역에 제공한다. 이미지에 적용한 CC BY-SA 조건은 해당 사진에 적용하며 앱 전체의 라이선스를 변경하지 않는다.

다운로드 내역과 SHA-256은 `.cache/medicine-photos/{topical,tablets,supplements}.json`에 보관했다. 세 사진의 합계 크기는 233,222바이트다.
