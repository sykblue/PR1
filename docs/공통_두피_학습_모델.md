# Gemini·Ollama 공통 두피 참고 모델

사용자 선택: 현재 Gemini API를 유지하면서 로컬 분류기를 학습하고, 그 결과를 Gemini 주 분석과 Ollama 백업 분석에 공통으로 전달한다. 두 제공자의 생성 모델 가중치를 각각 미세조정하는 작업과 구분한다.

## 처리 흐름

1. 사용자가 사진 분석에서 **추가 옵션 → 로컬 분류 보조 자료 → 확대 두피 사진의 학습 분류 결과를 AI에 함께 전달해요**를 선택한다. 기본은 꺼짐이며 새 사진·계정 변경 시 초기화된다.
2. 학습한 로컬 MobileNetV3 Small을 OpenCV CPU 추론으로 한 번 실행한다. 웹 서버에는 PyTorch를 추가하지 않는다.
3. `trained_scalp_reference`에 모델의 실험용 데이터셋 라벨·라벨 점수·불확실 여부·한계를 담아 Gemini 요청에 넣는다.
4. Gemini가 할당량 오류 `upstream_quota`를 반환하면 **동일한 참고 결과**를 Ollama 또는 선택한 기존 로컬 어댑터에도 전달한다. 인증 오류나 일반 오류로는 자동 전환하지 않는다.
5. 결과 화면과 텍스트/JSON 내보내기에 확대 두피 학습 참고 결과를 남긴다. 불확실한 모델 출력에는 등급을 표시하지 않는다.

사진 전송·기록 저장 동의는 기존 분석 흐름을 따른다. 로컬 학습 원본·정답·특징값을 Google에 보내는 경로는 추가하지 않았다. 학습 모델의 현재 사진 분류 결과만 사용자가 선택한 분석 요청에 함께 전달한다.

## 학습 자료와 분리

- 자료: [2026-11-02 검토한 데이터셋](탈모_데이터셋_검토_2026-11-02.md)의 18,513장.
- SHA-256 완전 중복 2,215개 사본을 제거해 **16,298장**을 사용한다.
- 같은 이미지의 라벨이 서로 다르면 준비 작업을 중단한다. 서로 다른 ID에 중복 배치된 이미지는 ID 목록을 보존하고 대표 ID를 정해 분할한다.
- 학습 11,047장, 검증 2,891장, 테스트 2,360장이다. 대표 ID와 정확히 같은 이미지가 학습/검증/테스트 사이에 겹치지 않는 것을 확인한다.
- 서로 다른 원본 ID 사이에 같은 이미지가 사용된 문제가 있으므로 실제 사람 단위의 완전한 독립성을 입증한 분할은 아니다. 성능은 이 수령본의 내부 평가이며 외부 검증·임상 성능이 아니다.
- 등급별 학습 비중을 고려해 클래스 가중 손실을 사용한다. 검증 macro-F1으로 최종 회차를 고르고, 그 뒤 테스트 세트는 최종 평가에 사용한다.

## 모델과 운영 구분

학습은 별도 `.venv-vlm`에서 ImageNet 사전학습 MobileNetV3 Small의 분류 헤드를 교체하고 일부 후반 특징 층을 조정한다. 공식 9.8MB 사전학습 가중치를 사용하며 웹 분석 시에는 ONNX 파일을 OpenCV에서 CPU로 읽는다.

검증 결과로 온도 보정을 선택한다. 모델의 라벨 점수가 기준보다 낮거나 상위 두 라벨의 차이가 작으면 `uncertain`으로 보류한다. 라벨 점수는 질환 확률이나 측정 정확도가 아니다.

`models/scalp-classifier/metadata.json`의 `onnx_verified`가 true여야 웹에서 활성화된다. 이는 PyTorch와 OpenCV 출력의 수치 일치를 확인한 표시이며 임상적 검증 표시가 아니다. 모델 SHA-256도 추론 시 검사한다.

일반 이마·헤어라인 사진에는 이 참고 모델을 자동 적용하지 않는다. 이 자료로 선천적 이마 형태·탈모 유무·과거 대비 후퇴를 확정할 수 없다. `hair-observation-v5-scalp-reference` 지시는 참고 라벨을 사람의 진단으로 옮겨 쓰지 않도록 명시하며 기존 이마/모발 영역 구분 검증을 유지한다.

## 2026-11-02 학습·적용 결과

RTX 4070 Laptop GPU에서 6회 학습을 완료했다. 검증 macro-F1 기준으로 4회차를 선택한 뒤 테스트 세트를 평가했다. 테스트를 보고 회차나 분할을 다시 고르지 않았다. 온도 보정 후보 중 검증 손실이 가장 낮은 값은 1.0이었다.

| 평가 | 사진 수 | 전체 일치율 | 등급별 균형 정확도 | Macro-F1 |
|---|---:|---:|---:|---:|
| 검증 | 2,891 | 66.7% | 61.9% | 0.556 |
| 테스트 | 2,360 | 65.8% | 61.2% | 0.520 |
| 테스트의 경증 고정 기준선 | 2,360 | 74.1% | 25.0% | 0.213 |

등급별 가중 손실을 사용한 모델은 고정 기준선보다 균형 지표는 높지만 전체 일치율은 낮다. 전체 일치율만으로 정확도가 향상됐다고 표현하지 않는다. 테스트의 양호·경증·중등도·중증 재현율은 각각 75.4%·68.8%·57.4%·43.3%이며, 특히 중증 참고 라벨의 구분에 한계가 있다. 이 수치는 불확실 결과를 제외해 높인 값이 아닌 전체 테스트의 4등급 분류 성능이다.

학습 가중치는 `data/scalp-training/job-20261102-123056/best.pt`, 배포된 로컬 추론 파일은 `models/scalp-classifier/model.onnx`다. 모델 SHA-256은 `3fcbe4a6ee25e30606bd913c5badfa9124d26b5724e596be4d82879712f5b147`이다. 검증 입력 8개의 PyTorch/OpenCV 출력 최대 절대 차이는 **0.000011683**으로 허용치 0.005 이내이며 `onnx_verified=true`를 확인했다. 실행 중인 로컬 서버를 최신 코드로 재시작했고 `/api/status`가 `scalp_reference.ready=true`와 자료 수 16,298장을 반환한다.

## 연결 검증

- 전체 Python 테스트 194개와 Node 테스트 137개가 통과했다. 새 테스트는 명시적 선택, 한 번의 분류, 두 제공자에 같은 참고 결과 전달, 429 이외 오류의 전환 금지, 불확실 결과 보류, 모델 검증, 중복·분할 검사를 포함한다.
- 실제 학습 파일과 실제 로컬 `qwen2.5vl:3b`로 분석했다. 클라우드 오류만 429로 모의하고, Ollama 호출과 분류기는 실제 실행해 `provider=ollama`, `fallback_reason=gemini_quota`, 위 모델 해시의 참고 결과가 반환되는 것을 확인했다. 원본 사진은 로컬에서만 처리했다.
- Gemini 실제 연결은 자체 합성 그림만 전송해 `422 photo_not_usable` 거절을 확인했다. 이 검사는 연결·부적합 입력 처리를 확인하며 실제 두피 사진 리포트의 품질을 입증하지 않는다. 두 제공자의 요청 본문에 같은 참고 결과가 들어가는 것은 별도의 자동 테스트로 검증했다.
- 실제 브라우저 렌더링은 이번 작업에서 검증하지 않았다. 학습 자료 원본·기존 사용자 DB·계정별 SVM 및 Qwen 모델은 변경하지 않았다.

## 재현 명령

```powershell
powershell -File scripts/setup_scalp_training.ps1
.\.venv\Scripts\python.exe scripts/prepare_scalp_dataset.py --source '탈모 데이터셋' --output data/scalp-training/dataset
.\.venv-vlm\Scripts\python.exe scripts/train_scalp_classifier.py --epochs 6 --batch-size 64
.\.venv\Scripts\python.exe scripts/verify_scalp_classifier.py
```

학습은 기존 비전 학습과 같은 GPU 잠금을 사용한다. 원본 TAR은 수정하지 않고, 정리한 JPG·분할 명세는 `data/scalp-training/dataset`, 작업 상태·최선 가중치는 `data/scalp-training/job-*`, 웹 추론 모델은 `models/scalp-classifier`에 둔다. 자료와 가중치 폴더는 Git에서 제외한다.
