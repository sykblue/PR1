## 표시 범위

- 성분 소개 사진 3종과 공통 출처·상담 블록을 제거하고 제품 20개 각각에 해당 제품의 실제 사진을 연결한다. 사진별 출처·표시 방식은 [의약품 제품 사진](의약품_제품사진.md)에 정리했다.
- 종류별 또는 제조·수입사별 묶음, 종류·업체 필터, 제품명·성분·제형·수탁 제조사 검색을 제공한다. 조건은 함께 적용하며 결과 수·빈 결과·초기화를 표시한다.
- 일반의약품과 전문의약품을 구분한다. 보조치료 의약품을 피나스테리드·두타스테리드나 일반 영양제와 같은 분류로 합치지 않는다. 마이녹실에스캡슐은 미녹시딜 성분 제품으로 표시하지 않는다.
- 제품별 허가된 성별·연령·효능이 다르므로 원문 링크를 제공한다. 함량은 제품 정보이며 개인별 복용량·조합·처방을 생성하지 않는다. 판매·재고·가격·효과 순위·구매 링크를 표시하지 않는다.
- 자료는 정적 목록이며 열 때 외부 API·위치·사용자 사진·계정 DB를 사용하지 않는다. 새 리포트·사진·계정으로 분석 상태를 초기화할 때 필터도 초기화한다.

## 확인 자료

앱 자료는 `static/medicine-catalog-data.js`다. 공식 검색 HTML·상세 HTML·추출 정보와 작성 스크립트는 `.cache/medicine-catalog/`에 보관한다. 이름이 비슷해도 수출용·다른 함량·다른 제형을 임의로 대체하지 않았다. 최초 후보 중 공식 검색과 일치하지 않은 제품은 목록에 넣지 않았다.

## 검증

전체 Node 테스트 147개가 통과했다. 실제 목록 20개·5종류·13개 업체, 일반/전문 구분, 조건의 동시 적용·검색 정규화·제조사별 묶음·빈 결과·초기화·새 리포트 초기화·텍스트 삽입·공식 URL 제한·외부 요청 미사용을 검증했다. 20개 품목의 식약처 명칭·업체·구분·품목번호·정상 상태를 수집 자료와 다시 대조했고 피나스테리드/두타스테리드 함량과 보조치료 의약품의 성분도 확인했다.

실행 중인 분석 HTML과 새 JS·CSS가 HTTP 200·no-store로 최신 파일을 제공하는 것을 확인했다. HTML의 고유 ID·레이블·ARIA 참조·스크립트 순서, JS 구문과 CSS 구획을 검사했다. 실제 브라우저 렌더링과 모바일 실기기 화면은 별도로 검증하지 않았다. 사용자 DB·사진·위치나 외부 AI 호출은 사용하지 않았다.
