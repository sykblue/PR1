## 표시·보관

- 포장 사진이 없는 아보투윈은 해당 품목의 실제 낱알 식별 사진으로 표시한다. 다른 브랜드나 제형의 사진으로 대체하지 않는다.
- 이미지 경로는 현재 품목 ID와 일치하는 로컬 정적 경로만 허용한다. 사진 출처는 확인한 식약처·유한양행·세계비즈 도메인으로 제한한다.
- 이미지에는 고유 대체 설명·크기·지연 로딩·비동기 디코딩을 지정한다. 로딩 실패 시 다른 약 사진을 보여 주지 않고 오류 문구를 표시하며 제품 정보와 필터는 유지한다.
- 각 사진의 원출처와 워터마크를 보존하며, 기존 Wikimedia 사진에 적용됐던 CC 라이선스를 새 사진의 라이선스로 표시하지 않는다.
- 원본 후보·선택 명세·출처 URL·바이트 수·SHA-256은 `.cache/medicine-product-photos/`에 보관한다. 실제 사용자 사진과 계정 DB는 사용하지 않는다.

## 검증

전체 Node 테스트 150개가 통과했다. 제품별 사진 20개·고유 경로·크기·대체 설명·지연 로딩·출처·확대 보기, 이미지 실패 처리와 외부/다른 품목 사진 경로 차단을 확인했다. 원본 바이트·SHA-256·이미지 디코딩·메타데이터의 크기를 대조했고 실제 서버의 20개 사진이 HTTP 200·이미지 MIME·no-store로 같은 바이트를 제공했다. 삭제한 블록이 실제 HTML에 없는지와 HTML ID·ARIA·JS 구문·CSS 구획도 확인했다. 실제 브라우저 렌더링은 별도로 검증하지 않았다.
