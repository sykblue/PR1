# 병원·치료제 모달

확인일: 2026-10-31

리포트의 **병원 찾기 / 약·치료제 안내** 버튼은 독립된 모달의 해당 탭을 연다. 완료 리포트와 본인 저장 리포트에서 사용할 수 있다.

## 요청에 따라 제거한 영역

‘나의 다음 행동’과 관찰 상태별 행동 문구, 느끼는 변화 확인, 선택 안내, 상담 준비 체크, 해당 AAD 링크를 모두 제거했다. 입력 상태와 행동 분기 코드도 정리하며 빈 왼쪽 열을 남기지 않는다.

‘진료 안내’라는 공통 제목 아래 최대 800px의 단일 면에서 두 탭을 사용한다. 선택된 탭은 파란 글자·밑줄·굵기로 표시한다. 병원 검색은 위치 아이콘·한 줄 제목·짧은 설명·주요 버튼을 하나의 배너로 합치고 방문 전 확인 2항목을 아래에 배치한다. 위치를 버튼 클릭 시에만 확인하고 저장하지 않는다는 안내는 항상 표시하며 구체적인 이용 안내는 native details로 펼친다. 약 탭은 제품 사진이 포함된 의약품 목록을 2열·600px 이하 1열로 표시한다. 검색 배너·방문 확인도 600px 이하에서 세로로 전환한다. 긴 내용은 탭 안에서 스크롤하고 하단에는 ‘리포트로 돌아가기’ 버튼만 둔다.

닫기·Esc·배경 클릭·원래 버튼으로 포커스 복귀를 유지한다. 탭은 좌우 방향키·Home/End로 전환한다. 모달을 여는 것만으로 위치나 병원 조회를 실행하지 않는다.

진료 안내 제목과 닫기 버튼이 있는 상단 영역은 투명 배경이다. dialog 자체의 흰 배경과 테두리를 없애고 본문·하단 버튼 영역에만 흰색 배경과 둥근 테두리를 둔다. 제목은 흰색 20px·굵게 표시하며 닫기 버튼은 투명 배경·흰 아이콘과 키보드 포커스 표시를 사용한다. 주변 병원 결과 모달은 기존 스타일을 사용한다.

## 병원 찾기

‘내 주변 병원 보기’는 두 번째 네이티브 dialog를 열고 버튼을 누른 경우에만 위치를 확인한다. 검증한 위도·경도를 소수 셋째 자리로 줄여 CSRF 보호 POST /api/clinics/nearby에 좌표와 반경만 보낸다. 사진·리포트·계정 내용은 요청에 넣지 않는다.

서버는 심평원 2026-09-30 공개 현황의 피부과 전문의 신고기관 1,744곳에서 2/5/10km 직선 거리를 계산한다. 가까운 최대 20곳과 전체 수를 반환하며 외부 지도·AI에 요청하거나 위치를 저장하지 않는다.

목록·상세 정보를 좌우로 표시하고 작은 화면에서는 세로로 전환한다. 주소·전화·등록 운영 시간, 주소 복사·전화 연결·공식 자료 출처를 제공한다. 미등록 정보는 명시하며 현재 근무·탈모 진료·운영 여부를 추측하지 않는다. 거리순은 치료 효과·평점 순위가 아니다. 방문 전 확인을 안내하며 [출처·라이선스·갱신](병원_데이터.md)을 표시한다.

검색 시작 화면은 위치 검색 카드와 방문 전 확인 목록으로 구성한다. 결과 모달의 검색 반경·다시 찾기는 상단에 두며 하단은 안내 복귀 버튼만 오른쪽에 표시한다. 사용자가 지정한 하단 공통 출처·공공누리 문구·기준일·현황 차이·위치 미저장 안내 블록은 제거했다. 병원 목록은 거리와 ‘선택됨’ 문구가 있는 카드로 표시하고 상세 정보와 스크롤을 나눈다. 데스크톱에서 주소 복사·전화 버튼은 상세 하단에 고정하며 병원을 바꾸면 상세 내용의 스크롤을 처음으로 돌린다. 760px 이하에서는 목록·상세를 세로로, 높이 600px 미만에서는 모달 전체 스크롤로 전환한다.

주소 입력과 Google 지도 연결은 없다. 위치 거절·시간 초과·미지원·잘못된 좌표·서버 오류·빈 결과를 구분하고 다시 찾기·범위 변경을 제공한다.

## 약 안내

사용자가 지정한 미녹시딜·피나스테리드·영양제 소개 사진 3개, 공통 사진 출처·이용 조건, 상담 문구와 AAD/NHS 링크 블록을 제거했다. 사진 분석에서 개인별 약물·용량·기간·적합성·상품을 자동 선정하지 않는다.

제품 20개 각각에 해당 품목의 사진을 넣는다. 제품 포장 사진 19개와 아보투윈의 실제 낱알 식별 사진 1개이며 식약처·제조사 제공 자료를 사용한다. 이미지를 누르면 로컬 원본 사진을 새 창으로 열고 출처는 각 카드의 짧은 링크로 표시한다. 사진의 내용·로고·워터마크를 변경하지 않으며 원본 전체를 표시한다. [사진별 출처 기록](의약품_제품사진.md)을 따른다.

식약처 허가정보로 대조한 제품 20종을 제공한다. 외용 미녹시딜 6종·외용 알파트라디올 1종·경구 피나스테리드 5종·경구 두타스테리드 5종·복합성분 보조치료 의약품 3종이다. 종류별/제조·수입사별 묶음과 종류·업체 필터·제품 검색을 함께 적용한다. 업체 분류는 식약처 품목허가 업체 기준이고 위탁 제조사는 별도로 표시한다. 일반/전문 구분·성분·함량·제형·허가 효능 요약·공식 원문 링크를 제공한다. [전체 품목·출처](탈모_의약품_목록.md)에 대조 기준을 남겼다. 정적 목록이므로 외부 조회·사용자 사진 분석·개인별 약 선정이나 가격/효과 순위 없이 동작한다.

## 상태와 구현

닫기·사진/관찰 부위/계정/리포트 변경 시 두 모달·좌표·검색 결과를 지우고 진행 중 요청을 취소한다. 분석 상태를 초기화할 때 의약품 검색·필터·묶음도 초기 상태로 되돌린다. 늦게 도착한 위치·병원 응답은 폐기한다. 두 번째 모달을 닫으면 첫 모달의 위치 버튼으로 돌아오며 목록은 위/아래 방향키·Home/End로 선택한다.

병원 정보는 textContent로 표시하고 전화·고정된 공식 출처 링크를 검증한다. 구현은 analysis.html, static/analysis-recommendations.js, static/recommendations-dialog.css, services/clinics.py에서 관리한다. 테스트는 실제 DOM의 모달·탭·키보드·포커스·위치 요청·CSRF·지연 응답과 제거된 입력 없이 초기화되는 동작을 확인한다.
