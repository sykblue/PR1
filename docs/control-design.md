# 버튼과 세부 요소 디자인

사용자 요청에 따라 [제공된 One UI 참고 문서](references/Samsung-One-UI_사용자제공.md)를 **버튼과 세부 컨트롤에만** 적용한다. 전체 화면은 [공통 디자인](../디자인.md)의 기존 리디 참고 구성과 파랑 #0066FF를 유지한다. 이 문서는 컨트롤 기준이며 메인·헤더와 기능별 본문 구성은 공통 디자인을 따른다. 2026-11-01 추가 요청으로 중앙 로고·메뉴·메인 시작 표시의 공통 스타일을 통일했다.

원문은 삼성이 만든 공식 문서 자체가 아닌 공개 자료의 비공식 요약이다. 18dp 버튼 수치는 원문이 인용한 구현 스펙, 썸네일 수치는 One UI 2(2019) 자료에서 가져온 값이다. 웹의 18px·12px·20px 대응과 적용 대상은 이 제품의 선택이며 현행 삼성 시스템 전체의 공식 규격으로 표현하지 않는다.

## 적용한 요소

| 요소 | 적용 |
| --- | --- |
| 주요 버튼 | 기존 파랑·흰 글자, 18px 모서리, 기존 44/48px 조작 높이 유지 |
| 보조 버튼 | 중립 회색 면·짙은 글자, 같은 18px 모서리와 누름 피드백 |
| 툴바·텍스트 행동 | 평상시 평평한 면, 호버·누름 시 회색 표면, 명확한 키보드 포커스 |
| 입력·검색 | 12px 모서리, 연한 중립색 면, 포커스 시 선과 바탕 구분 |
| 라디오 선택 카드 | 12px 모서리, 기존 네이티브 라디오와 선택 표시 유지 |
| 체크박스·슬라이더 | 기존 입력 크기와 값 유지, 둥근 체크 표시·손잡이, 선택·비활성·포커스 구분 |
| 접이식 항목 | native details/summary 유지, 호버 표면과 펼침 아이콘 피드백 |
| 기록·카메라 창 | 기존 위치·크기 유지, 20px 모서리, 기존 딤과 그림자를 중복 적용하지 않음 |
| 도우미·메시지·결과 안내 | 기존 동작·배치 유지, 둥근 선택 버튼·메시지·상태 구획 |

컨트롤 전환은 `160ms cubic-bezier(0.22, 0.25, 0, 1)`이며 움직임 줄이기 설정에서 기존 공통 규칙에 따라 제거한다. 160ms는 원문의 100~500ms 범위에서 고른 제품 값이다. 누름 확대·축소는 transform만 사용해 주변 배치를 움직이지 않는다.

입력은 내부 스크롤 경계에서도 보이도록 안쪽 2px 포커스 선을 사용한다. 버튼의 외곽 포커스, 네이티브 입력·키보드 조작·체크 상태·라벨 연결은 유지한다. 강제 고대비 모드에서는 체크박스·슬라이더의 네이티브 외형을 사용한다. 버튼의 44/48px 높이와 기존 한글 서체·글자 크기는 이 프로젝트 기준이며 삼성의 공식 수치로 설명하지 않는다.

원문의 대형 앱바·하단 내비게이션·다크 모드·폰트·화면 분할 비율은 이번 요청에 적용하지 않는다. 사용자 요청의 기존 메인과 배치가 우선이다. 새 테마 파일·외부 폰트·라이브러리를 추가하지 않으며 기존 CSS와 역할별 `--radius-*`, `--control-motion` 변수를 사용한다.

## 검증

HTML·기능 스크립트와 메인 CSS의 변경 여부, 기존 배치·크기·타이포그래피 선언 보존, CSS 구문·토큰·실제 자산 응답, 기존 기능 테스트를 확인한다. 실제 화면·터치·고대비·확대 검증 여부는 [개발 기록](개발%20기록.md)에 따로 기록하며 정적 검사로 대체했다고 표현하지 않는다.
