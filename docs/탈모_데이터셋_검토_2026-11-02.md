# 새 탈모 데이터셋 검토

검토일: 2026-11-02

새 파일은 두피 확대 이미지의 등급 분류를 실험할 자료로 검토할 수 있다. 현재 앱의 일반 이마·헤어라인 사진 인식에 그대로 적용해 성능이 좋아진다고 판단할 근거는 없다. 샘플의 촬영 방식이 다르고, 완전 중복·클래스 불균형·누락된 라벨 자료를 먼저 처리해야 한다. 이번 작업에서는 데이터와 모델을 학습에 등록하지 않았다.

## 확인한 파일과 수량

대상은 프로젝트의 `탈모 데이터셋` 폴더에 있는 TAR 4개다. 전체 크기는 4,369,686,016바이트, 약 4.37GB다. 기존에 일부 풀려 있던 `download (3)` 폴더의 분할 파일은 원본 TAR과 같은 자료이므로 다시 합산하지 않았다.

| TAR 파일 | 내부 폴더의 탈모 등급 | JPG 수 | 비율 |
| --- | --- | ---: | ---: |
| `download.tar` | 0. 양호 | 534 | 2.88% |
| `download (1).tar` | 1. 경증 | 13,346 | 72.09% |
| `download (2).tar` | 2. 중등도 | 3,797 | 20.51% |
| `download (3).tar` | 3. 중증 | 836 | 4.52% |
| 합계 | 4등급 | **18,513** | **100%** |

내부 경로는 `148.한국인_두피_상태_이미지/01.데이터/1.Training/원천데이터/6.탈모/…`다. 제공된 4개 TAR 모두 Training 원천데이터 부분이다. 별도 Validation/Test 폴더와 JSON·CSV·설명서는 이 4개 TAR 안에 없다.

경증 ZIP은 `.part0`, `.part1073741824`, `.part2147483648`의 3분할이고 나머지 ZIP은 각각 `.part0` 하나다. 숫자 오프셋 순서로 연결한 가상 스트림에서 ZIP을 읽어 전체를 검사했다. 원본 TAR을 변경하거나 4GB짜리 병합 ZIP·전체 이미지 폴더를 별도로 만들지는 않았다.

## 파일 품질 검사

18,513개 파일 모두 ZIP CRC 확인과 Pillow의 전체 픽셀 디코딩을 수행했다. SHA-256은 JPEG 파일 바이트 전체에 계산했다.

| 항목 | 확인 결과 |
| --- | ---: |
| JPEG 이미지 | 18,513장 |
| 해상도 | 전부 640 × 480 |
| 색상 모드 | 전부 RGB |
| ZIP 읽기·CRC 또는 이미지 디코딩 오류 | 0건 |
| EXIF / GPS 태그 포함 | 0 / 0건 |
| 160px 미만 이미지 | 0장 |
| 거의 단색인 이미지 | 0장 |
| 이름이 같은 파일 | 0쌍 |
| SHA-256이 같은 파일 | **2,215쌍** |
| 중복 제거 시 남는 고유 파일 | **16,298장** |
| 서로 다른 등급 사이의 완전 중복 | 0쌍 |

완전 중복 2,215쌍은 총 4,430개 파일이 참여하며, 각 쌍에서 하나씩 제외하면 2,215장, 전체의 11.96%를 줄일 수 있다. **파일명이 달라도 바이트가 같은 이미지가 있고, 비식별 ID가 다른 중복 사례도 확인됐다.** 따라서 이름 비교나 사람별 분할만으로 중복 유출을 막을 수 없다. 먼저 전체에서 중복을 제거한 다음 그룹을 나눠야 한다. 이번 검사는 완전 중복 검사이며, 크롭·재압축·유사 촬영 이미지 전체의 중복 여부까지 판정한 것은 아니다.

파일 손상이 없다는 결과가 임상 라벨의 정확성이나 촬영 품질 전체를 보증하지는 않는다. 단색 검사는 축소한 RGB 표본의 채널별 표준편차 최대값 1 미만만 찾는 제한적인 검사다.

## 촬영 방식과 그룹

등급마다 2장씩, 총 8장을 육안 확인했다. 모두 모발과 두피 표면을 크게 촬영한 이미지였다. 일반 정면·이마 전체·헤어라인 외곽 사진과 입력 형태가 다르다. 모든 이미지를 육안 판독한 것은 아니다.

공식 [AI Hub 유형별 두피 이미지 설명](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=216)은 파일명을 비식별 ID·단말기 ID·이미지 일련번호·촬영부위로 설명하고, 탈모 라벨을 JSON의 `value_6`으로 정의한다. 이 명명 구조와 현재 파일들의 구조가 일치한다. 촬영부위 코드의 의미도 해당 설명을 기준으로 아래에 정리했다.

| 촬영부위 코드 | 공식 설명의 부위 | 현재 이미지 수 |
| --- | --- | ---: |
| TH | 정수리 | 7,387 |
| LH | 좌측두 | 4,415 |
| RH | 우측두 | 4,488 |
| BH | 후두부 | 2,223 |

- 파일명 앞부분의 비식별 ID는 185개다. 이것을 검증된 실제 인원 수로 단정하지 않는다.
- 185개 중 166개 ID가 두 개 이상 등급에 들어 있다. 등급은 각 이미지의 폴더 라벨로 다루며, ID 전체의 단일 진단으로 합치지 않는다.
- 비식별 ID·단말기 ID 조합은 223개다. 같은 ID를 단말기가 다르다는 이유로 다른 학습/검증 그룹에 넣지 않도록 해야 한다.
- 비식별 ID·단말기 ID·일련번호 조합 중 여러 이미지가 있는 경우는 4,986개다. 이미지 단위 무작위 분리는 같은 ID와 연관 촬영 이미지가 양쪽에 들어갈 수 있다.

## 학습 전에 해결할 점

1. **완전 중복을 제거한 뒤 비식별 ID로 분할한다.** 동일 이미지가 서로 다른 ID에도 있으므로 순서가 중요하다. 검증·테스트 세트는 이 데이터 수령본 안에 별도로 제공되지 않았다.
2. **등급 불균형을 고려한다.** 경증이 양호의 약 25배다. 원본 분포에서 무조건 경증으로 답해도 4등급 단순 일치율은 72.09%다. 양호와 나머지로 단순 이진화하면 나머지로만 답해도 97.12%이므로 높은 전체 일치율만으로 좋은 모델이라고 판단하면 안 된다.
3. **라벨 JSON을 확보해 폴더 등급과 대조한다.** 현재는 등급 폴더 외에 이미지별 `value_6`, 다른 두피 항목, 메타데이터를 교차 확인할 자료가 없다. 공식 사이트에 JSON 형식이 정의돼 있지만 이번 로컬 다운로드에는 포함되지 않았다.
4. **확대 두피 이미지와 일반 헤어라인 사진을 구분한다.** 이번 자료의 학습 결과가 넓은 이마·선천적 헤어라인·실제 변화 구분에 일반화되는지는 별도 사진과 정답으로 평가해야 한다.

## 현재 앱과의 연결 판단

- `services/training.py`의 로컬 분류기는 기준/의심의 2개 사용자 라벨과 최대 500장을 지원하는 HOG·색상 특징 기반 SVM이다. 이번 4등급 18,513장을 그대로 넣는 일괄 학습 경로는 없다. 상한이나 라벨을 임의로 바꿔 등록하지 않았다.
- Qwen 비전 학습은 최대 200장과 구조화된 관찰 정답 JSON을 요구한다. 이번 자료는 JPG와 폴더 등급만 있어 그 정답 형식과도 직접 맞지 않는다. 폴더의 중증도만으로 관찰 정답을 자동 생성해 확정 라벨처럼 사용해서는 안 된다.
- 확대 두피 이미지용 분류 실험을 별도 목표로 정한다면 중복 정리·ID별 분할·등급 검증부터 진행할 수 있다. 현재 이마·헤어라인 기능의 개선 효과는 측정하지 않았다.

## 후속 학습 완료

이 보고서는 최초 자료 검토 시점의 판단이다. 이후 사용자가 현재 API를 유지하며 로컬 분류 결과를 Gemini·Ollama에 공통 반영하는 방식을 선택해 별도 확대 두피 분류기를 학습했다. 완전 중복 제거 후 16,298장을 사용했으며 기존 계정별 SVM·Qwen 학습과 분리했다. 실제 학습 성능·분할의 한계·연결 검증과 사용 방법은 [공통 두피 학습 모델](공통_두피_학습_모델.md)에 기록했다.
