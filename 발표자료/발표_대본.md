## 발표 전에 확인할 것

- [ ] 2장의 '대상 사용자' 문장은 문서에 명시된 내용이 아니라 정리한 표현이다. 본인이 생각한 대상과 맞는지 확인한다.
- [ ] 화면 캡처는 비로그인 상태 데스크톱 1440px 첫 화면이다. 화면이 더 바뀌면 `화면캡처/`를 다시 찍는다.
- [ ] 제출 필수물: GitHub 주소 + 발표 자료(PDF). 배포 주소나 1~3분 시연 영상 중 하나를 추가로 준비해야 한다(아직 없음).
- [ ] 테스트 수가 바뀌면 9장 숫자와 그래프를 함께 고친다.
